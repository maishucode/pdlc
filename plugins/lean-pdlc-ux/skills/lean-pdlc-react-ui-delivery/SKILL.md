# React UI delivery

Use this skill only after an approved UX state matrix or design reference is supplied.

## Required work

- Implement the approved UX state matrix in existing React conventions.
- Create focused component and interaction tests for the changed behavior.
- Run the smallest relevant existing test command and report the command and outcome as evidence.

## Constraints

- Do not invent design decisions. You cannot change scope beyond the approved design reference.
- Do not install dependencies or change project tooling.
- Do not approve PDLC decisions, Build Readiness, or acceptance.
- Use only the Stage binding's allowed work and report uncertainty instead of guessing.
