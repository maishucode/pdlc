## How to answer

Fill every `[Answer]:` tag. Use the option letter plus a short explanation when useful. If no option fits, choose `X` and write the intended behavior. Do not change the question IDs.

This questionnaire contains only unresolved product decisions. Do not ask the user to restate enterprise, project, or Harness standards that the applicable profiles already resolve; those standards are shown separately in the final Requirements document. Product-specific behavior must still be confirmed even when a standard supplies the corporate baseline.

When finished, save this file and tell the Agent to re-read it. The Agent will validate completeness, check contradictions, and copy resolved decisions into the Requirements document as `RQ-xxx` entries.
