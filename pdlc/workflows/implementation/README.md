# Implementation Workflow Reservation

Owner: **PDLC Governance**.

This folder reserves the future executable Implementation workflow for delivery that starts from approved requirements or an existing work item and continues through implementation, QA preparation, sign-off, and release controls. Its planned Stage composition is already defined in `pdlc/journeys/implementation.json`.

It is not executable. Activation requires an approved `workflow.json`, schemas, Runner support, tests, and integration behavior for JIRA, XRAY, CI evidence, and release tollgates.
