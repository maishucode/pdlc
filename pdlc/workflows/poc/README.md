# POC Workflow Ownership

Primary owner: **PDLC Governance**. Product Governance owns `requirements-policy.json`.

This is the only executable workflow in Phase 1. Its ordered Stage composition is defined in `pdlc/journeys/poc.json`; reusable Stage requirements are defined in `pdlc/stages/catalog.json`. Changes to Journey composition, delivery defaults, constraints, requirements coverage, or checkpoint definitions require governance review and Harness regression tests.
